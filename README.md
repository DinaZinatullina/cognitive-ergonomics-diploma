# Двухуровневая система когнитивной эргономики

Выпускная квалификационная работа (ВКР). 
Проект представляет собой веб-приложение (SCADA-интерфейс) для мониторинга психофизиологического состояния оператора высокотехнологичных отраслей.

## Основные возможности

Система реализует два уровня когнитивной эргономики:

1. **Валидация контента:** 
   - Автоматический анализ текстов на наличие канцеляризмов и сложных конструкций.
   - "Умная" замена тяжелых слов на более простые (встроенный фильтр).
2. **Поведенческая адаптация:**
   - Сбор телеметрии (клики, время реакции, ошибки, простой).
   - Расчет интегрального показателя когнитивной нагрузки (`cognitive_load_score`).
   - Динамическое упрощение интерфейса (скрытие второстепенных панелей, увеличение шрифта) при превышении порога нагрузки.
   - Предиктивное предупреждение аварийных ситуаций на основе анализа трендов.

## Технологический стек

- **Backend:** Python 3.12, Django 6.1
- **Frontend:** JavaScript (Vanilla), HTML5, CSS3
- **База данных:** SQLite (для dev-среды)
